Protocol

MeshCore moves the packets.

The radio layer is MeshCore, the open LoRa mesh from meshcore-dev. UpstreamMesh is the flood sensing we are building on top of it. We do not maintain MeshCore, and this page is not their documentation.

Their site is meshcore.io. Supported radios are flashed from meshcore.io/flasher. The library is MIT licensed. Companion, repeater, room, and sensor roles already exist there. How the five nodes map onto those roles is still open.

The twelve bytes further down are a draft of a flood payload carried inside that mesh. They are not MeshCore's own packet format, and they are not implemented. The picture is a model of five roles along one river. Distances are absent because they are not measured. Nothing starts until you press a button.

Sleep until the beacon

A LoRa radio that listens all the time draws on the order of 10 mA. That empties a small pack. The draft sleeps, then wakes for one beacon. The listen window has to cover that beacon's airtime. At SF10 and 125 kHz a 12-byte frame is on the air for a few hundred milliseconds, so a short slot only works if the beacon uses a faster spreading factor. A weak hop can drop to a slower one.

This is a power goal for the sensor nodes. MeshCore does not use this schedule. How it would sit on a MeshCore repeater or companion is still open.

SX1276 receive current is about 10–12 mA in the datasheet. Transmit current depends on power. Sleep current of a whole node depends on the regulator, and it will not be the chip's deep-sleep figure. Those are bounds for the design, not a measurement of a built unit.

A 12-byte draft, and no more

Heartbeat, telemetry, and the alert share one layout so a small receiver can parse it. The last four bytes are a truncated tag plus a counter. That raises the cost of a blind forgery. It is not a full HMAC-SHA256, and it does not by itself stop a determined attacker. The plain-text copy is docs/frame.md.

Byte 0

Type

0x01 heartbeat and time. 0x02 sensor report. 0xFF emergency alert.

Bytes 1–4

Network time

uint32 seconds. The gateway's notion of UTC. A node that just booted has only its own uptime until it hears one.

Byte 5

Basin state

0 nominal, 1 advisory, 2 surge. On the first five, surge is the frame and the log, plus a buzzer if someone is there.

Bytes 6–7

Stage delta

int16 centimeters from the node's own baseline. Two upstream nodes have to agree before it becomes an alert.

Bytes 8–11

Tag

Four bytes. A truncated authenticator and a counter, so a replay of an old surge is obvious. A budget choice, not a security proof.
